Scientific safeguards

What the interactive model does—and does not—claim.

It does: expose both equations, animate seeded stopped paths, preserve packet identity in a ledger, compare telemetry proxies, and make the information-loss hypothesis explorable.
It does not: treat M = 0 as semiclassically valid, call the browser contrast transfer entropy, infer a theorem from one sample path, or replace the trained float64 likelihood engine.
