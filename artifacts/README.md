# Generated artifacts

The canonical pipeline writes versioned JSON summaries beneath this directory.
Generated outputs are excluded from Git so that simulations remain reproducible from
configuration, source code, and random seed.

Expected families:

- `part0/model_validation.json`
- `part1/paradigm_a_summary.json`
- `part2/paradigm_b_summary.json`
- `part3/information_summary.json`
- `part4/validation_summary.json`
