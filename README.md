# Black Hole Information Dynamics

A research-grade PyTorch framework for comparing discrete and continuous
statistical experiments generated by an evaporating black hole.

The project supports a Statistics PhD thesis investigating whether a smooth,
continuous representation masks information-theoretic signatures retained by
discrete stochastic emission events.

## Research question

The primary estimand is the integrated information residual

\[
\Delta_I(T)=I_B(T)-I_A(T),
\]

where:

- **Paradigm A** is a stopped, non-homogeneous marked point process with
  \(\lambda(M_t)=\gamma/M_t\) and Planck-distributed energy marks;
- **Paradigm B** is a stopped Itô diffusion
  \(dM_t=-\alpha M_t^{-2}dt+\sigma_{\rm base}M_t^{-1}dW_t\).

The directional thesis hypothesis is \(\mathbb E[\Delta_I(T)]<0\): continuum
coarse-graining transmits less information to the detector filtration.

## Canonical research stack

The repository follows an auditable production order inspired by the supplied
sample project:

**Part 0 -> Part 1 -> Part 2 -> Part 3 -> Part 4**

1. `part0_validate_model.py` validates physical parameters and moment matching.
2. `part1_simulate_paradigm_a.py` summarizes discrete packet trajectories.
3. `part2_simulate_paradigm_b.py` summarizes continuous diffusion trajectories.
4. `part3_information_engine.py` computes likelihood scores, Fisher matrices,
   entropy drifts, and information contrasts.
5. `part4_validate_repository.py` runs the numerical test suite.

`run_research_pipeline.py` executes the complete sequence and stops on the first
failed stage.

## Methodological safeguards

- All paths stop at a positive cutoff `m_floor`; the code does not claim that a
  semiclassical model is valid at \(M=0\).
- Fisher scores differentiate fixed realized paths. They are not confused with
  pathwise derivatives through the simulator.
- The native three-parameter Fisher matrices are structurally singular. The
  engine pulls both models back to the common parameter
  \((M_0,\alpha_{\rm eff})\) before comparison.
- The requested diffusion is retained, but a moment-matched control is included.
  Paradigm A implies diffusion scale proportional to \(M^{-3/2}\), not \(M^{-1}\).
- An information contrast is labeled transfer entropy only when the reduced
  predictor is conditioned causally on detector history. The default ensemble
  baseline is explicitly labeled as an open-loop diagnostic.

## Installation

Use Python 3.12 for local and CI reproducibility.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
```

On Windows PowerShell, activate with `.venv\Scripts\Activate.ps1`.

## Quick start

Run the complete validated pipeline:

```bash
python run_research_pipeline.py --replicates 64 --seed 20260820
```

Or use the installed command-line interface:

```bash
bhid validate --config configs/baseline.json
bhid run --config configs/baseline.json --replicates 64 --seed 20260820
```

The baseline study writes:

```text
artifacts/part0/model_validation.json
artifacts/part1/paradigm_a_summary.json
artifacts/part2/paradigm_b_summary.json
artifacts/part3/information_summary.json
artifacts/part4/validation_summary.json
```

Generated artifacts are intentionally excluded from version control.

## Tests

```bash
python -m unittest discover -s tests -v
ruff check .
```

The numerical suite verifies Planck moments, both path likelihoods, inactive
parameter directions, Fisher positive semidefiniteness, matrix dimensions, and
finite autograd results.

## Current research boundary

The engine implements the exact information functionals given predictable reduced
intensities/signals. A causal marked-point-process filter for A and nonlinear filter
for B remain required before the final thesis results may be labeled transfer
entropy. Until then, default outputs are open-loop likelihood-information contrasts.
