Ṡ = 𝔼[ℓfull(dYt) − ℓreduced(dYt)] / dt

The current ensemble uses leave-one-out, open-loop predictors. It is therefore an information diagnostic, not yet a continuous-time transfer-entropy estimator.

Required next layer: causal marked-point filtering for A and nonlinear continuous-time filtering for B, both conditioned on the same detector history.

Core hypothesis

Does smoothing conceal information?

The directional claim is E[ΔI(T)] < 0: the continuum observation paradigm transmits less detector information than discrete emissions.

Fisher geometry

Compare common coordinates.

Native three-parameter Fisher matrices are structurally singular because γ is absent from B and α is absent from A. Pull both models back to (M₀, αeff).

HMC / NUTS

Regularize before the cutoff.

As M approaches zero, λ, drift, and diffusion explode. Positive transforms, stopped paths, non-centered constructions, and metric regularization are computational necessities.

Scientific safeguards

What this interface does—and does not—claim.

It does: expose model equations, reproduce the validated baseline information snapshot, animate seeded sample paths, and document the exact inferential boundary.
It does not: treat M = 0 as semiclassically valid, call an open-loop contrast transfer entropy, or substitute browser arithmetic for the PyTorch likelihood engine.
